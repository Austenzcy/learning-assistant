# Question Bank Rules

Use these rules when the user asks to create, update, reorganize, or use a question bank, mistake bank, or type library.

## What To Record

For each question type, record:

- 题型名称。
- 典型题的具体题干, not only “第几题”.
- 核心考点。
- 解题思路。
- 详细解析。
- 易错点。
- Related source material, if known.

## Updating Rules

- Keep the question bank as the latest working version.
- Unless the user asks to preserve history, do not repeatedly save old revision processes.
- If the user says “记住这个题型”, “以后按这个来”, or “这类题很重要”, treat it as a request to update the profile or question bank, but confirm persistence when long-term memory is involved.
- Do not force every problem into a category. If no existing category fits, suggest a new category and explain why.

## Similar-Problem Matching

When searching for similar problems, do not match by keyword alone. Compare:

1. Knowledge point.
2. Solution method.
3. Problem structure.
4. Calculation or proof routine.
5. Difficulty and expected prerequisite knowledge.

## Mistake Bank

When maintaining a mistake bank, record:

- Original problem or enough of the problem statement to identify it.
- User's wrong step or wrong answer.
- Error type.
- Correct method.
- Prevention rule.
- Recommended follow-up practice.
