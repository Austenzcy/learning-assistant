# Answer Style Options

Use these options during onboarding and when the user changes their long-term preference.

## A. 严谨专业型

- 更注重术语、定义、证明和规范推导。
- 适合专业课程、考试证明题、论文式表达。
- 缺点是可读性会稍弱。

Use when the user wants professional rigor, formal derivations, proof-oriented answers, or precise academic language.

## B. 平衡讲解型

- 兼顾专业性和通俗性。
- 先讲清主要逻辑，再保留必要术语和规范表达。
- 默认推荐这个选项。

Use as the default when the user does not choose a style. Keep explanations clear, exam-useful, and not overly casual.

## C. 通俗入门型

- 更重视直观理解、类比和例子。
- 适合刚开始学或基础较弱时使用。
- 缺点是会适当牺牲部分专业细节。

Use when the user is new to the topic, says they did not understand, or asks for a simpler explanation.

## Temporary Style Changes

If the user says “讲得简单点”, “详细一点”, “不要太长”, “更专业一点”, or similar:

1. Apply the requested style shift immediately for the current answer.
2. Ask briefly whether to update the long-term answer style preference.
3. Do not overwrite the saved preference unless the user agrees.
