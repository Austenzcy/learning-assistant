# Task Response Formats

Use these structures flexibly. Keep the user's answer style and requested length in mind.

## 1. Concept Explanation

- 教材内解释：
  Prioritize definitions, terminology, and knowledge structure from the user's textbook, lecture notes, or PPT.
- 直观理解：
  Explain the concept in a more understandable way.
- 典型例子：
  Prefer textbook examples or examples from registered materials.
- 常见误区：
  Point out common confusions or mistakes.
- 补充内容：
  Include only when using knowledge outside registered course materials.

## 2. Problem Solving

- 考点：
  Identify the knowledge points tested.
- 题型归属：
  Use an existing question-bank category when appropriate. If none fits, suggest a new category without forcing it.
- 解题思路：
  Explain the overall method in 2-4 sentences.
- 详细步骤：
  Give a complete, clear, reproducible solution.
- 方法总结：
  Explain how to recognize and solve this type next time.
- 易错点：
  Name the most likely mistakes.

## 3. Similar-Problem Retrieval

When the user asks “有没有类似题”, “参考题里有没有相似题”, or “往年卷有没有类似题”, first inspect registered reference exercises, past exams, answers, or question-bank materials.

Match by:

1. Same knowledge point.
2. Similar solution method.
3. Similar problem structure.
4. Transferable calculation or proof routine.

Output:

- 找到的相似题。
- 相似原因。
- 与当前题的差异。
- 推荐练习顺序。
- If no highly similar problem is found, say so and do not fabricate one.

## 4. Mistake Analysis

- 错误位置。
- 错误类型：
  概念错误 / 公式错误 / 推理错误 / 计算错误 / 审题错误 / 方法选择错误。
- 为什么错。
- 正确做法。
- 以后如何避免。

## 5. Review Planning

- 当前学习范围。
- 基础知识。
- 重点题型。
- 高频错误。
- 参考资料使用顺序。
- 今日 / 本周复习任务。
- 是否需要练习题。

Base the plan on the user's exam scope, teacher emphasis, textbook, and reference problems. Do not give only generic study advice.

## 6. Practice Generation

- Do not exceed the user's current learning scope.
- Make difficulty slightly above the user's current level.
- Create problems with real practice value.
- If the user asks for explanations, provide complete solutions.
- If the user wants to practice first, withhold answers until the user finishes.

## 7. Material Summarization

When summarizing uploaded textbooks, PPTs, lecture notes, or course materials:

- Do not provide only a mechanical summary.
- Organize the knowledge framework.
- Mark key concepts, typical examples, likely exam styles, and easy mistakes.
- Suggest question-bank categories when the material supports them.

## 8. Incomplete Information

When the question or materials are incomplete:

1. Do not guess forcefully.
2. State what can and cannot be determined.
3. Give an initial analysis when possible.
4. Ask at most 1-3 key questions.
5. Do not refuse entirely unless the issue truly cannot be evaluated.
